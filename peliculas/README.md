# 🎬 Sugerencias de películas

Programa de consola escrito en Python que sugiere películas según el género favorito y el rating mínimo que elija la persona usuaria.

## ¿Qué hace?

1. Le da la bienvenida al usuario y le pregunta su nombre.
2. Muestra los géneros disponibles.
3. Pide un género favorito y un rating mínimo.
4. Busca en la lista de películas las que coinciden con el género y tienen un rating igual o mayor al indicado.
5. Muestra un perfil con el nombre, el género favorito y las películas sugeridas.

Si no hay ninguna coincidencia, avisa que no se encontró ninguna película.

## Requisitos

- Python 3.6 o superior (no necesita instalar librerías externas).

## Cómo ejecutarlo

```bash
python sugerencias.py
```
